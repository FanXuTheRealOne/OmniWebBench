# OmniWebBench v0.2.0 — 100-task proportional preview

Released 2026-08-11.

## What shipped

- 100 deterministic public development tasks;
- six exact track quotas: 25 / 18 / 12 / 15 / 10 / 20;
- 41 capability labels and all five scoring profiles exercised;
- 17 new deterministic research briefs;
- 19 new browser diagnosis and code-patch cases, bringing the Coding/Debug track to 20;
- fixture coverage and passing-reference evidence for every task;
- the unchanged 24-task v0.1 pack for regression comparisons.

## Status

This remains a public developer preview. The research tasks use deterministic source boards, and the patch tasks use browser-visible code fixtures. Live-web, repository-backed, verified and hidden-test environments remain admission-gated future work.
