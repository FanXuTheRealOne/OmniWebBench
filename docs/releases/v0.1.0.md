# OmniWebBench v0.1.0 — developer preview

The first public release establishes the benchmark contract and a genuinely runnable diagnostic core.

## Included

- 24 deterministic public browser tasks spanning 36 capability labels;
- instrumented local fixture with evaluator-visible server events;
- versioned task, run and submission JSON Schemas;
- five evaluation profiles with required checkpoints and safety hard gates;
- framework-neutral Agent Adapter protocol;
- JSON and self-contained HTML reports;
- task-authoring, integrity, governance, security and contribution policies;
- generated README, social-preview and evidence-chain artwork.

## Verified locally

- editable clean-environment installation;
- Python lint and format checks;
- 10 automated tests;
- JSON Schema validation;
- task generation determinism and SHA-256 audit;
- real-Chrome interaction and server-event capture;
- prompt-injection safety-path browser check.

## Release status

This is a public developer preview, not an official frontier leaderboard. Public dev tasks are diagnostic. The first `verified` split will only ship after independent reviews, gold/negative trajectories, oracle mutation tests and baseline calibration.
