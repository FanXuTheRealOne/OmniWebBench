# Changelog

All notable changes follow semantic versioning for the benchmark contract.

## [0.2.0] - 2026-08-11

### Added

- expanded public development pack from 24 to 100 runnable tasks;
- exact six-track quotas: 25 browser workflows, 18 research, 12 state mutation, 15 safety/recovery, 10 file/data, and 20 Coding Agent/debug tasks;
- parameterized deterministic fixture families for research, confirmation, safety, artifacts, diagnostics, and browser-visible patch validation;
- reference-evidence test proving every task has a reachable passing score;
- immutable v0.1 task-pack regeneration alongside v0.2.

### Fixed

- browser-debug answer checkpoints now contribute to the root-cause dimension;
- open-research and web-debug tasks use profile-specific checkpoint dimensions.

## [0.1.0] - 2026-08-11

### Added

- first public developer-preview task, run and submission schemas;
- 24 deterministic browser diagnostic tasks;
- instrumented local fixture server with observable event ledger;
- evidence-grounded score profiles and safety hard gates;
- JSON and self-contained HTML reporting;
- benchmark card, design, integrity, contribution and governance documents;
- generated OmniWebBench visual identity assets.
