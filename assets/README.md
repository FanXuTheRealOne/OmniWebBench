# Brand assets

These assets were generated for OmniWebBench with OpenAI's built-in image-generation tool on 2026-08-11. A supplied visual reference was used to identify high-level qualities: warm paper texture, hand-cut botanical silhouettes, asymmetrical density, generous negative space and a vivid ultramarine/red/orange/green/black palette. No source logo or product mark was copied.

## Files and final prompts

### `hero.png`

Ultra-wide, text-free GitHub README banner with Matisse-inspired cut-paper botanical forms concentrated on the right and a warm paper field on the left. This remains available as a secondary decorative asset.

### `social-preview.png`

Primary GitHub README and social card with the exact title **OmniWebBench**, the line “100 RUNNABLE TASKS · 6 TRACKS”, and the positioning statement “Built for agentic browsers.” The typography sits in a quiet paper field while cut-paper botanical forms frame the right and lower edges.

### `matisse-divider.png`

Panoramic cut-paper botanical divider using the same warm paper texture and color system as the primary repository artwork.

### `evidence-chain.png`

Legacy dark panoramic evidence-chain banner retained for release-history compatibility. It is no longer used on the repository homepage.

The prompts were executed in built-in image-generation mode. Final images were inspected for spelling, composition, unwanted logos and visual consistency before being added to the project.
