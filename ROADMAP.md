# Roadmap

## v0.1 — developer preview

- [x] Public schemas and framework-neutral run contract
- [x] Deterministic instrumented fixture
- [x] 24 diagnostic browser tasks
- [x] Evidence-grounded scorer and hard gates
- [x] JSON and HTML reporting
- [x] Safety, recovery and browser-debug probes
- [x] Public governance and task-authoring policy

## v0.2 — verified diagnostic split

- [x] 100 deterministic tasks across six tracks
- [x] 20-task Coding Agent / browser-debugging track
- [ ] Two independent reviewers per task
- [ ] Oracle mutation testing tool
- [ ] Signed fixture event receipts
- [ ] Gold and negative trajectories
- [ ] Baselines across screenshot, AX-tree and hybrid agents
- [ ] Human completion and inter-rater calibration
- [ ] Capability-level report dashboard

Release gate: zero known false-positive oracles, fixture reset success ≥99.5%, and reviewer agreement ≥90%.

## v0.3 — stateful and visual suites

- [ ] Containerized mail, commerce, forum, map and issue-tracker sites
- [ ] Database and network oracles
- [ ] Visual-only, DOM-only and hybrid matched tasks
- [ ] Accessibility and responsive/mobile slices
- [ ] File upload/download and structured-artifact verification

## v0.4 — open web and research

- [ ] Read-only live-web task pack
- [ ] URL- and timestamp-bound claim evaluator
- [ ] Drift monitor and task validity service
- [ ] Three-repeat protocol with uncertainty intervals
- [ ] Multilingual matched tasks

## v0.5 — repo-to-browser debugging

- [ ] Containerized repositories with seeded browser-visible defects
- [ ] Console, network, source and visual checkpoints
- [ ] Fail-to-pass and pass-to-pass tests inspired by SWE-bench
- [ ] Visual-diff and accessibility regression oracles
- [ ] Root-cause and patch-minimality scorecards

## v1.0 — official benchmark

- [ ] Frozen audited test split
- [ ] Official verified leaderboard
- [ ] Reproduction service and signed bundles
- [ ] Dataset card, archival DOI and technical paper
- [ ] Independent steering and reproduction reviewers
