# Brand assets

These assets were generated for OmniWebBench with OpenAI's built-in image-generation tool on 2026-08-11. A supplied visual reference was used only to identify high-level qualities—cool-white light, rounded modular geometry, generous negative space and restrained typography. No source logo, product mark or navigation layout was copied.

## Files and final prompts

### `hero.png`

Ultra-wide GitHub README hero for **OmniWebBench** with the exact line “Measure what web agents actually do.” Cold-white frosted browser tiles recede around an obsidian measurement core; graphite and small cyan accents; premium minimal research-lab identity; no external marks, people or watermark.

### `social-preview.png`

GitHub social card with the exact title **OmniWebBench** and line “A capability-first benchmark for web agents.” An ordered field of translucent browser modules frames a black measurement sphere with restrained cyan guides; readable under social-card cropping; no external marks or watermark.

### `evidence-chain.png`

Dark panoramic documentation banner showing five frosted browser slabs linked through a black core by cyan evidence lines; graphite, smoke glass and off-white; no text, logos, people or watermark.

The prompts were executed in built-in image-generation mode. Final images were inspected for spelling, composition, unwanted logos and visual consistency before being added to the project.
